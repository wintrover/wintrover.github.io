fix(verification): Q4 replay-harness subject dep resolution — explicit nimble dep roots for the d2-agent stamped harness

Root cause (docs/spec/replay_harness_config_quirks.md Q4): the d2-agent
carrier's replay harness imports the subject's public API, whose closure
reaches the subject's nimble dep stack (stew/enums at reader.nim:12).
Nim 2.2.10's lazy nimble-path discovery resolves those deps only when the
compile is invoked from a neutral cwd — the identical command from
cwd=Axiom3 repo root fails with 'cannot open file: stew/enums'
(reproduced: cwd=ROOT exit 1 / cwd=/tmp exit 0, same command, pristine
subject 4aa8e22). The skip-cfg flags are invariant: this is the
compiler's built-in path discovery, not config inheritance.

Fix (mechanism-independent): ReplayConfig gains depSearchPaths; the d2-agent
replay path resolves the subject dep roots (serialization, faststreams,
stew, results) at runtime from the nimble store (pkgs2 -> pkgcache -> pkgs,
newest version wins, module-presence validated) and pins them as explicit
--path: entries appended after the subject paths. AXIOM_REPLAY_DEP_PATHS
(design (b)) overrides discovery wholesale; a missing package fails closed
with a diagnostic naming it. Scoping: resolution fires only on the stamped
harness path AND only when the subject tree's import statements actually
name the stack — self-contained stamped subjects (unit fixtures) and every
collateral harness (C_out/base36/base32, self-kernel) stay zero-diff.

cmd construction is refactored into the pure buildHarnessCmd (unit-locked
to the pre-Q4 shape when depSearchPaths is empty). Empirical: with the 4
discovered roots the harness compiles+runs from cwd=ROOT
(AXIOM_REPLAY_BEGIN/false/AXIOM_REPLAY_END, exit 0 — the defect witness).

Tests: import-statement scanning (multi-line lists, comment cutting,
json_serialization collision guards), version ranking/newest-wins, pkgcache
slug matching, env override fail-closed, buildHarnessCmd zero-diff lock,
and a real nim c -r end-to-end proving depSearchPaths is load-bearing
(rvAgree with the dep root; rvUnavailable without). Neighbor suites
(test_toml_d2_agent_binding, test_base36_cout_binding,
test_bug_verdict_projection) green.
